### 3.3 Анализ результатов

- **Для больших матриц** (от 800×800 и выше):  
  Увеличение числа процессов даёт значительное ускорение. При 8 процессах время выполнения сокращается в 4–5 раз по сравнению с последовательной версией.

- **Для малых матриц** (200×200, 400×400):  
  Ускорение нелинейно и ограничено из-за накладных расходов на передачу данных и синхронизацию между процессами.

- **Пример для матрицы 2000×2000:**  
  - 1 процесс: 53.99 сек  
  - 8 процессов: 11.81 сек  
  - Ускорение: **4.57 раза**

## 4) Выводы

- Технология MPI позволяет эффективно распараллеливать умножение матриц.
- С увеличением размера матрицы эффективность параллелизации возрастает.
- Для задач малого размера накладные расходы на коммуникацию могут снижать выигрыш от использования множества процессов.
- Наибольший эффект достигается при использовании 4–8 процессов для матриц размером от 800×800 и выше.
