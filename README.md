# 1. Задание

Модифицировать программу из лабораторной работы №1 для параллельной работы по технологии **OpenMP**.

Провести серию экспериментов с различными размерами матриц и различным количеством потоков.

Размеры матриц:

- 200×200
- 400×400
- 800×800
- 1200×1200
- 1600×1600
- 2000×2000

Количество потоков:

- 1 поток (последовательное выполнение)
- 2 потока
- 4 потока
- 8 потоков

# 5. Выводы

Параллельное выполнение программы с использованием технологии **OpenMP** позволяет значительно увеличить производительность при работе с большими матрицами.

Наилучшие результаты достигаются при использовании **8 потоков**, что существенно уменьшает время выполнения по сравнению с последовательным алгоритмом.

Для небольших матриц (например 200×200 и 400×400) использование большого количества потоков не даёт значительного выигрыша из-за накладных расходов на создание потоков.

Таким образом, параллелизация наиболее эффективна для задач с большим объёмом вычислений.
